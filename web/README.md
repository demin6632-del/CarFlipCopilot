# AUTOFLIP web shell

Статический адаптивный frontend-каркас на HTML, CSS и JavaScript без runtime-зависимостей и сборщика.

## Локальный просмотр

Откройте `index.html` в браузере или запустите любой статический HTTP-сервер из этой папки.

## Текущее ограничение

Это публичная информационная оболочка и визуальный прототип будущего кабинета. Авторизация, профиль, гараж, API и реальные объявления ещё не подключены. Демо-элементы не представляют игровые данные.

## Проверки перед расширением

- Проверить HTML/CSS/JS и адаптивность на мобильном и desktop.
- Добавить автоматические smoke-тесты структуры и доступности.
- Согласовать и реализовать API-контракт с сервером.
- Только после отдельного согласования создавать Render Static Site и домен.
